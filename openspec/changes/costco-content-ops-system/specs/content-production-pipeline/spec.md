## ADDED Requirements

### Requirement: USDA API integration fetches nutritional data
The system SHALL include `scripts/usda-nutrition.js` that queries the USDA FoodData Central API by food name and outputs structured nutritional data to `src/content/data/usda/` as JSON files.

#### Scenario: USDA script fetches hot dog nutrition
- **WHEN** a developer runs `node scripts/usda-nutrition.js "hot dog"`
- **THEN** a JSON file is created in `src/content/data/usda/` containing calories, protein, fat, carbs, and sodium per 100g

### Requirement: Content research script aggregates Google related questions
The system SHALL include `scripts/content-research.js` that accepts a keyword and outputs a Markdown draft to `src/content/drafts/` containing: related questions from Google "People also ask", Reddit thread titles from r/Costco, and a suggested article outline.

#### Scenario: Research script generates draft
- **WHEN** a developer runs `node scripts/content-research.js "costco rotisserie chicken"`
- **THEN** a Markdown draft file appears in `src/content/drafts/` with a title, target keyword, related questions section, Reddit insights section, and a 5-section outline

### Requirement: Draft files use standardized frontmatter for AI-assisted production
All draft files generated by the pipeline SHALL include frontmatter fields: `title`, `targetKeyword`, `sources` (array of URLs), `generatedAt`, `status` (draft|review|published), and `aiAssisted` (boolean).

#### Scenario: Draft frontmatter is complete
- **WHEN** a developer opens a generated draft file
- **THEN** all required frontmatter fields are present and `status` is set to `draft`

### Requirement: Pipeline respects API rate limits
All external API calls in the pipeline SHALL implement rate limiting: minimum 1 second between USDA API requests, minimum 3 seconds between Google/Reddit requests, and a maximum of 50 requests per run.

#### Scenario: Rate limiting prevents blocks
- **WHEN** the research script processes a batch of 10 keywords
- **THEN** the total execution time is at least 30 seconds due to enforced delays between requests

### Requirement: Drafts require human review before publishing
No draft generated by the pipeline SHALL be directly published. The `status` field MUST transition from `draft` → `review` → `published` only through manual developer action.

#### Scenario: Draft cannot auto-publish
- **WHEN** the research script completes execution
- **THEN** the generated file has `status: draft` and no build script will automatically move it to the published articles directory
