### 2.2 典型用户场景

**场景 1：第一次去 Costco 的消费者**

```
用户：从来没去过 Costco
搜索词："costco hot dog what is it"
真正问题："听说很有名，到底怎么样？值得排队吗？"
内容需求：详细介绍、用户评价、价格历史、购买攻略
```

**场景 2：健康饮食者**

```
用户：正在控制饮食或健身
搜索词："costco hot dog calories" / "costco hot dog macros"
真正问题："这个有多少卡路里？蛋白多少？适合我的饮食计划吗？"
内容需求：详细营养成分、对比其他快餐、热量计算器
```

**场景 3：宗教/饮食限制人群**

```
用户：穆斯林/犹太教/素食者/过敏者
搜索词："is costco hot dog halal" / "are costco hot dog buns vegan"
真正问题："我的宗教/健康限制，能吃吗？"
内容需求：成分溯源、认证状态、明确的是/否答案
```

**场景 4：想在家复刻的爱好者**

```
用户：喜欢在家做饭
搜索词："how to cook costco hot dogs at home"
真正问题："怎么在家做出和 Costco 一样的味道？"
内容需求：烹饪方法、配方揭秘、空气炸锅/烤箱/煎锅做法
```
